# 界面样例

本目录收录指挥 Agent / Agent Leader 的静态界面样例，以及可点击原型的运行截图。图中为示例数据，非正式视觉定稿；图中点击为交互示意。较早版本多写「指挥 Agent」，可点击原型截图已使用项目名 Agent Leader。

未收录各版本的绘图脚本（`render_*.py`），也未收录可点击原型的源码（此前已单独打包为 `agent-leader-prototype.tar.gz`）。
