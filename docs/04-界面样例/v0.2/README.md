## 相对 v0.1 的结构调整（按用户新决策）
- 左侧是项目名称列表，可新建项目。
- 新建项目以两个主输入框为主：项目背景/情况，项目要达成的目标；项目名称只在顶部补一行。
- 指挥按背景朝目标拆解，拉起多个 Agent 同步工作；用户不必逐个指派。
- 工作台用卡片网格展示团队，区分「执行中 / 已回报指挥 / 指挥已验收 / 待启动」。
- 中间持续与指挥 Agent 对话；项目汇总独立成区，统一告知完成情况和下一步。
- 点击卡片打开详情：上下文、当前任务、进展与产物、向指挥的回报，以及汇总后按依赖安排测试的闭环。
- 单项或背景任务完成不等于项目完成；依赖未满足的测试保持待启动。
